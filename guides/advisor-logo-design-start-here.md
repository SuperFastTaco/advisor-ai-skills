# Create a Logo for Your Advisory Practice

Create a new logo or refresh an existing one. The agent reviews your materials before asking questions.

## Start in Codex

Install [the complete skill folder](https://github.com/SuperFastTaco/advisor-ai-skills/tree/main/skills/advisor-logo-design) by asking Codex:

> Use the skill installer to install skills/advisor-logo-design from SuperFastTaco/advisor-ai-skills.

Then start with:

> Use $advisor-logo-design to review my branding guide, website, existing logos, and brochures. Answer the intake questions from those materials first, ask only unanswered questions, and create three distinct logo concepts for my practice.

Share what you have, including any firm instructions. Starting from scratch is fine. Advisor-branding-rules.md and readable PDF brand guides are accepted.

## Review and refine

The agent summarizes its findings, asks only remaining questions, and shows distinct concepts with a brief explanation.

Choose a direction and describe your changes:

> Keep the second concept's symbol. Make the firm name easier to read and show a clean one-color version for a pen.

When you are ready for the selected handoff:

> Prepare the selected logo assets and Advisor-logo-rules.md. Identify remaining production work and provide the approved changes for my branding guide.

## Image-generation choices

Codex uses its available built-in image tool without requiring an API key.

Other capable agents can use the bundled helper with your own Gemini or OpenAI API account. Choose the provider and model, set the key locally, and agree on the generation scope. API billing is separate. Do not paste keys into chat.

If generation is unavailable, use the supplied prompts in an image tool and bring the results back for review.

## Use the instruction PDF

Attach the instruction PDF and say:

> Follow this Advisor Logo Design PDF. Review my materials first, ask only unanswered questions, and create logo concepts using the tools available here.

The PDF provides guidance; native installation and helper execution need the complete folder. Native installation in other agents and live paid API calls remain unverified.

## Keep the finished assets together

Keep accepted assets with Advisor-logo-rules.md and your brand guide. Generated images are raster concepts; genuine vector artwork needs construction and verification. The agent identifies unfinished production work.

Your materials and finished logos stay outside the shared skill package.
